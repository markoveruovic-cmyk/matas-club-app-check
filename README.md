# Matas Club — App Review Analysis

User review analysis of the Matas Club mobile app (Google Play & Apple App Store), prepared by Etnetera Flow.

- **Report:** [`index.html`](index.html) — open locally in a browser, or serve via GitHub Pages (Settings → Pages → deploy from branch).
- **Sample:** 1,000 Google Play reviews (Oct 2019 – Jun 2026) and 148 App Store reviews (Nov 2023 – Jun 2026).
- **Contents:** an "Insights from research" overview, key statistics, four technical pain points by platform, 26 verbatim user quotes (Danish originals with English translations).

The report is a single self-contained HTML file; fonts (Montserrat, Google Fonts) and the Etnetera Flow logo are loaded from CDN.
